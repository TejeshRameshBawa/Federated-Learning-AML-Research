# Federated Learning AML Research

Research proposal for Anti-Money Laundering as a Service using federated learning, privacy-preserving collaboration and governance. Includes separate coursework labs.

**Project type:** Academic AML architecture/research report with supporting labs.

## What the work covers

- Proposes collaboration between financial institutions without centrally pooling their underlying transaction data.
- Discusses federated averaging, privacy-preserving methods and model-update workflows.
- Connects the proposed architecture with AML investigation, escalation and governance considerations.
- Includes course lab documents and notebooks as separate learning artefacts.

## Run or read the work

Read `Report.pdf` for the architecture, motivation and limitations. The notebooks and documents under `Labs` should be inspected individually for their inputs and environment assumptions; they are not an integrated implementation of the proposed federated AML service.

## Scope and limitations

This is a research/design proposal rather than a deployed inter-bank system. Privacy methods and regulatory frameworks are discussed, not independently certified. No measured fraud-detection improvement or demonstrated end-to-end federated training performance is asserted.
